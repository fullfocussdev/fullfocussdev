# Website Astro — interface para serviços de IA

> **Estudo de caso de portfólio · Frontend · Website · Estudo de interface**

## Visão geral

Projeto local baseado em um template de agência de IA e consultoria, trabalhado como estudo de implementação e customização de experiência web. A autoria do template-base não é reivindicada neste portfólio.

## Trabalho e áreas envolvidas

- Estudo de arquitetura de páginas e componentes Astro
- Experimentos de animação e responsividade
- Organização de conteúdo e apresentação de serviços

## Tecnologias identificadas

Astro · TypeScript · GSAP · CSS

## Aspectos técnicos apresentados

- Estrutura estática de páginas
- Animações de rolagem com GSAP
- Organização de assets e cuidados de SEO técnico

## Sobre a publicação

Este repositório apresenta **somente uma descrição pública do trabalho e, quando disponível, material visual de divulgação autorizado**. Não contém código-fonte, dados de produção, credenciais, integração privada ou arquivos originais do projeto.
