# Credmais Mobile — painel de gestão de dispositivos

> **Estudo de caso de portfólio · Aplicação web · Gestão operacional**

## Visão geral

Projeto de painel web para operação comercial e administrativa relacionada a dispositivos móveis, contratos e acompanhamento de serviços. O estudo descreve apenas a camada de produto e experiência, sem divulgar mecanismos internos ou dados de clientes.

## Trabalho e áreas envolvidas

- Organização de interface de painel administrativo
- Fluxos para consulta e gestão de cadastros e contratos
- Estruturação de telas e componentes React

## Tecnologias identificadas

React · Vite · Vitest · estrutura Android e backend

## Aspectos técnicos apresentados

- Separação entre frontend, serviços e módulos Android
- Estrutura voltada à operação administrativa
- Testes e organização da aplicação web

## Sobre a publicação

Este repositório apresenta **somente uma descrição pública do trabalho e, quando disponível, material visual de divulgação autorizado**. Não contém código-fonte, dados de produção, credenciais, integração privada ou arquivos originais do projeto.
