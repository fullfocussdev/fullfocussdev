# CredmaisPay — site e experiência digital

> **Estudo de caso de portfólio · Website · Fintech · UI/UX**

![Apresentação visual — CredmaisPay — site e experiência digital](../assets/credmaispay-hero.webp)

## Visão geral

Experiência web institucional voltada à apresentação de soluções financeiras digitais e à comunicação com o público. A abordagem reúne páginas de informação, navegação por produtos e elementos visuais de marca.

## Trabalho e áreas envolvidas

- Construção de páginas web institucionais e comerciais
- Design responsivo e composição visual
- Organização da navegação e das seções informativas
- Animações e interações para uma experiência mais fluida

## Tecnologias identificadas

React · React Router · Vite · GSAP · Motion · Lucide React

## Aspectos técnicos apresentados

- Arquitetura de componentes React
- Roteamento entre páginas
- Animações aplicadas com propósito de comunicação
- Materiais visuais para páginas comerciais

## Sobre a publicação

Este repositório apresenta **somente uma descrição pública do trabalho e, quando disponível, material visual de divulgação autorizado**. Não contém código-fonte, dados de produção, credenciais, integração privada ou arquivos originais do projeto.
