# Credcartas — experiência web

> **Estudo de caso de portfólio · Website · Design digital · Animação**

![Apresentação visual — Credcartas — experiência web](../assets/credcartas-hero.png)

## Visão geral

Projeto de experiência web de comunicação comercial para serviços financeiros, com foco na apresentação visual, fluidez e clareza das informações.

## Trabalho e áreas envolvidas

- Estruturação e apresentação de páginas comerciais
- Desenvolvimento de elementos visuais e composição de interface
- Adaptação da experiência a diferentes telas
- Uso de animações e transições

## Tecnologias identificadas

Vite · GSAP · Motion

## Aspectos técnicos apresentados

- Organização de assets e componentes de frontend
- Comunicação visual em páginas de produtos e serviços
- Interações de interface e responsividade

## Sobre a publicação

Este repositório apresenta **somente uma descrição pública do trabalho e, quando disponível, material visual de divulgação autorizado**. Não contém código-fonte, dados de produção, credenciais, integração privada ou arquivos originais do projeto.
