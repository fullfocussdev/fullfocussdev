# EloLab — plataforma de gestão clínica

> **Estudo de caso de portfólio · SaaS · Software de gestão · UX/UI**

![Apresentação visual — EloLab — plataforma de gestão clínica](../assets/elolab-site.png)

## Visão geral

Projeto de plataforma SaaS para unificar operações de clínicas e laboratórios. O produto contempla organização de atendimentos, agendamentos, recepção, módulos clínicos, rotinas de laboratório, financeiro e fluxos administrativos. **Em desenvolvimento.**

## Trabalho e áreas envolvidas

- Modelagem de experiência e navegação entre módulos operacionais
- Estrutura de interface para diferentes perfis e fluxos da clínica
- Implementação frontend e integração de dados
- Planejamento de testes, controle de acesso e evolução de produto

## Tecnologias identificadas

React · TypeScript · Vite · Tailwind CSS · Supabase · Framer Motion · Playwright · Vitest

## Aspectos técnicos apresentados

- Arquitetura modular para uma aplicação de múltiplos módulos
- Separação de responsabilidades e dados entre ambientes e usuários
- Interfaces responsivas e componentes reutilizáveis
- Boas práticas de privacidade aplicáveis ao contexto de saúde

## Sobre a publicação

Este repositório apresenta **somente uma descrição pública do trabalho e, quando disponível, material visual de divulgação autorizado**. Não contém código-fonte, dados de produção, credenciais, integração privada ou arquivos originais do projeto.
